## 단가 변경 과정 분석 결과

### 현재 시스템 구조

1. **standardwage_tb 테이블**
   - ID=1 단일 레코드로 모든 단가 관리
   - 히스토리 추적 기능 없음
   - sw_date 필드는 "1000-01-01 00:00:00"로 의미 없는 값

2. **변경 이력 추적 불가**
   - standardwage 전용 히스토리 테이블 없음
   - standardhistory_tb는 공사 표준항목용
   - history_tb는 일반 이력용
   - 데이터베이스 감사 로그 없음

### 24년도 → 25년도 단가 변경 과정 (추정)

**현재 값:**
- 개발 DB (dev.netb.co.kr): 223,644원 (24년도 단가)
- 운영 DB (10.34.96.4): 235,459원 (25년도 단가, 추정)

**변경 방법 (가능성 순서):**

#### 1. 직접 SQL UPDATE 쿼리 실행 (가장 가능성 높음)
```sql
-- 운영 데이터베이스에서 직접 실행
UPDATE standardwage_tb 
SET sw_person5 = 235459,
    sw_person1 = 432440,  -- 기술사
    sw_person2 = 358273,  -- 특급기술자
    sw_person3 = 300980,  -- 고급기술자
    sw_person4 = 284046   -- 중급기술자
WHERE sw_id = 1;
```

**도구:**
- MySQL Workbench
- phpMyAdmin
- DataGrip
- 터미널에서 mysql 명령어

#### 2. REST API 호출 (가능하지만 UI 없음)
```bash
# PUT /api/standardwage 엔드포인트 사용
curl -X PUT https://service.anbweb.kr/api/standardwage \
  -H "Authorization: Bearer <JWT_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1,
    "person1": 432440,
    "person2": 358273,
    "person3": 300980,
    "person4": 284046,
    "person5": 235459
  }'
```

**문제점:**
- 프론트엔드에 단가 수정 UI가 구현되지 않음
- Estimate.vue는 조회만 가능 (입력 필드 없음)

#### 3. 백엔드 코드로 직접 실행
```go
manager := models.StandardwageManager{Conn: conn}
wage := manager.Get(1)
wage.Person5 = 235459
manager.Update(wage)
```

### 개선 제안

1. **히스토리 테이블 추가**
```sql
CREATE TABLE standardwage_history_tb (
  swh_id BIGINT PRIMARY KEY AUTO_INCREMENT,
  swh_standardwage_id BIGINT NOT NULL,
  swh_year INT NOT NULL,
  swh_person1 INT NOT NULL,
  swh_person2 INT NOT NULL,
  swh_person3 INT NOT NULL,
  swh_person4 INT NOT NULL,
  swh_person5 INT NOT NULL,
  -- ... 기타 필드
  swh_created_by VARCHAR(50),
  swh_created_at DATETIME NOT NULL,
  swh_note TEXT,
  INDEX idx_year (swh_year),
  INDEX idx_standardwage (swh_standardwage_id)
);
```

2. **프론트엔드 수정 UI 추가**
   - Estimate.vue에 편집 기능 추가
   - 관리자 권한 체크
   - 변경 이력 저장

3. **트리거로 자동 히스토리 기록**
```sql
CREATE TRIGGER standardwage_update_history
AFTER UPDATE ON standardwage_tb
FOR EACH ROW
BEGIN
  INSERT INTO standardwage_history_tb 
  (swh_standardwage_id, swh_year, swh_person1, swh_person2, 
   swh_person3, swh_person4, swh_person5, swh_created_at)
  VALUES 
  (OLD.sw_id, YEAR(NOW()), NEW.sw_person1, NEW.sw_person2,
   NEW.sw_person3, NEW.sw_person4, NEW.sw_person5, NOW());
END;
```
